# CineRate – Movie Review & Rating System

CineRate is a web-based movie review and rating system built using Python, Flask, MySQL, HTML, CSS and JavaScript.

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Features

- User registration
- User login and logout
- Movie listing
- Search movies
- Filter movies by language
- View movie details
- Rate movies
- Write movie reviews
- View average movie ratings
- User dashboard
- MySQL database
